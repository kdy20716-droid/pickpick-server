## 핵심 기능 3가지

## 메인 페이지

- 간단하게 화면 (바로가기)
- 브랜드 세계관
- 책상 위

## 바로가기 눌렀을 시 -> 데스크에 제품이 꾸며진 리스트

- 카테고리 : 2유형 -> 톤앤톤, 분위기
- 사진 + 총액 가격

## 데스크 제품 들어간 사진 눌렀을 시 -> 여기에 들어간 제품 목록

- 제품 가격 합산된 결과
- 제품을 누르면 해당 구매 사이트로 이동
- 좋아요 기능 <- 인테리어에 대한 좋아요(즐겨찾기)
- 데스크 제품들에 대한 리뷰 / 별점 (이건 백엔드가 할 일이라 선택권 -> 기준 순위)
